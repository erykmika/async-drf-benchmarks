# Benchmarks

## Run all benchmarks

```bash
make benchmark-all
```

## Run Variant S benchmarks

```bash
make run-s-benchmark
```

## Run Variant A benchmarks

```bash
make run-a-benchmark
```

## Run CPU benchmarks

```bash
make run-s-benchmark-cpu
make run-a-benchmark-cpu
```

## Run IO benchmarks

```bash
make run-s-benchmark-io
make run-a-benchmark-io
```

## Run mixed benchmarks

```bash
make run-s-benchmark-mixed
make run-a-benchmark-mixed
```
